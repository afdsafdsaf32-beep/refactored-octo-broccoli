# PhoneVR — MVP

Стриминг рабочего стола ПК на iPhone как стерео-VR с управлением камерой через
гироскоп телефона (поворот головы = поворот взгляда в игре). Работает и по
WiFi, и по USB (см. `docs/usb-connection.md`).

## Структура

- `pc-server/server.py` — захват экрана, кодирование в H.264 (ffmpeg),
  раздача по TCP; приём ориентации от телефона и превращение её в движение
  мыши (mouse-look) для игр с видом от первого лица.
- `ios-client/PhoneVR/` — Swift/SwiftUI-исходники iOS-клиента: приём и
  декодирование H.264 (VideoToolbox), стерео-вывод на два "глазка", отправка
  данных гироскопа (CoreMotion).
- `docs/usb-connection.md` — как подключиться по USB (через USB Ethernet,
  без изменения кода приложения).

## Запуск ПК-сервера

```powershell
pip install mss
# ffmpeg.exe должен быть в PATH
python pc-server/server.py
```

## Сборка iOS-клиента

Файлы в `ios-client/PhoneVR/` — исходники без `.xcodeproj`. Чтобы собрать:

1. В Xcode: File → New → Project → iOS App (SwiftUI, Swift).
2. Замени сгенерированные `ContentView.swift` / `<Name>App.swift` файлами из
   этой папки, добавь `NetworkClient.swift`, `H264Decoder.swift`,
   `MotionSender.swift`.
3. В настройках таргета добавь содержимое `Info.plist` (ключ
   `NSLocalNetworkUsageDescription` обязателен, иначе iOS заблокирует сетевые
   запросы).
4. Local Network capability не требует явного entitlement, но при первом
   запуске iOS спросит разрешение — надо разрешить.

CI/CD (сборка `.ipa` через GitHub Actions) — следующий шаг после того, как
локальный прототип заработает и будет протестирован на реальном устройстве.

## Известные ограничения MVP

- Пока это не полноценный ALVR-уровня стриминг: нет адаптивного битрейта,
  нет пересчёта задержки, нет линзовой дисторсии/барр-дисторшн коррекции для
  Cardboard-очков (просто дублирование картинки на 2 половины экрана).
- Управление камерой — через инъекцию относительного движения мыши на ПК,
  так что работает только с играми/приложениями с обычным mouse-look.
- Один активный клиент одновременно (сервер держит одно TCP-соединение на
  каждый порт).
