# Сборка .ipa через GitHub Actions с бесплатным Apple ID

Без Mac и без платного Developer Program ($99/год) единственный рабочий
вариант — подписывать приложение "personal team" от твоего обычного Apple ID
прямо на macOS-раннере GitHub Actions. У этого пути есть жёсткие ограничения:

- Подписанный .ipa работает **7 дней**, потом нужно пересобрать (просто
  перезапустить workflow — задача берёт последний код и создаёт новый .ipa).
- Apple ID со включённой двухфакторной аутентификацией (2FA, а она сейчас
  обязательна) не даёт войти полностью "невидимо" в CI с одного пароля —
  нужен один разовый шаг с твоей стороны, чтобы обойти интерактивный запрос
  кода подтверждения.

## Шаг 1. App-specific password

1. Зайди на https://appleid.apple.com → Sign-In and Security → App-Specific
   Passwords → Generate.
2. Сохрани этот пароль — он пойдёт в секрет `APPLE_APP_SPECIFIC_PASSWORD`.

## Шаг 2. Разовая авторизация fastlane (обход интерактивного 2FA в CI)

Это единственное место, где нужен реальный компьютер (Windows подходит,
Mac не обязателен) с установленным Ruby:

```bash
gem install fastlane
fastlane spaceauth -u твой_apple_id@example.com
```

Она спросит код 2FA один раз (придёт на твои доверенные устройства), после
чего выведет длинную строку — это и есть сессия. Скопируй её целиком.

## Шаг 3. Секреты в GitHub

Repo → Settings → Secrets and variables → Actions → New repository secret:

| Имя | Значение |
|---|---|
| `APPLE_ID` | твой Apple ID (email) |
| `APPLE_APP_SPECIFIC_PASSWORD` | пароль из шага 1 |
| `FASTLANE_SESSION` | строка из шага 2 |

Сессия из `spaceauth` тоже не вечная (обычно около месяца) — когда сборка
начнёт падать с ошибкой авторизации, просто повтори шаг 2 и обнови секрет.

## Шаг 4. Первый запуск

Actions → "Build iOS .ipa" → Run workflow. Если всё настроено, в конце
появится артефакт `PhoneVR-ipa` — скачай `.ipa` из вкладки Actions.

## Установка .ipa на iPhone

GitHub Actions только собирает и подписывает файл — установить его на
телефон без App Store можно через:

- **Sideloadly** (Windows/Mac) — самый простой вариант с обычным Apple ID.
- **AltStore** — тоже поддерживает автопереустановку раз в 7 дней по WiFi.

## Когда это всё-таки стоит $99/год

Если пересборка/переустановка каждую неделю надоест — платный Apple
Developer Program уберёт лимит в 7 дней (профиль живёт год) и заодно
позволит использовать честный `sync_code_signing`/`match` без обхода 2FA
через `spaceauth` (App Store Connect API key работает полностью headless).
