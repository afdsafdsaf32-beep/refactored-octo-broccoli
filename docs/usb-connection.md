# Подключение по USB

## Почему не через usbmuxd/iproxy

Изначально здесь была инструкция с `iproxy` (утилита из `libimobiledevice`),
но она в корне не подходит для нашей схемы: `usbmuxd`/`iproxy` умеет
прокидывать соединения только в одну сторону — **ПК подключается к
телефону**. У нас же везде наоборот: телефон сам набирает исходящие
соединения к ПК (и в mouse-look режиме, и в SteamVR-режиме). Такое
usbmuxd в принципе не туннелирует — у iOS-приложений (без джейлбрейка) нет
доступа к обратному каналу через этот демон.

## Как работает USB на самом деле: USB Ethernet

Когда iPhone подключён к Windows кабелем (и установлены драйверы Apple —
обычно ставятся вместе с iTunes), в диспетчере устройств/сетевых
подключениях появляется виртуальный адаптер **"Apple Mobile Device
Ethernet"**. Это настоящий IP-канал поверх USB-кабеля, как если бы это был
Ethernet-кабель.

Чтобы телефон получил IP-адрес в этой сети и мог достучаться до ПК:

1. На Windows: **Панель управления → Сеть и Интернет → Сетевые подключения**.
2. Найди адаптер, через который у ПК есть интернет (WiFi или обычный
   Ethernet), правой кнопкой → **Свойства → вкладка "Доступ"** → включи
   **"Разрешить другим пользователям сети использовать подключение к
   Интернету этого компьютера"**, и в выпадающем списке домашней сети
   выбери **"Apple Mobile Device Ethernet"**.
3. После этого у адаптера "Apple Mobile Device Ethernet" появится IP вида
   `192.168.137.1` (стандартный диапазон ICS) — это и есть IP, который
   нужно вводить в приложении при выборе транспорта **USB**. Узнать точно:
   `ipconfig` в cmd, найти секцию "Ethernet adapter... (Apple Mobile Device
   Ethernet)" → IPv4-адрес.
4. Телефон при этом должен подхватить IP в той же подсети автоматически
   (Apple выдаёт DHCP-адрес на этом линке) — если не заработало сразу,
   попробуй отключить/переподключить кабель или проверить в настройках
   телефона (Настройки → Wi-Fi/сотовая сеть там не участвует, это отдельный
   канал, специально настраивать на телефоне ничего не нужно).

## В приложении

Выбери транспорт **USB** в переключателе на экране подключения — под ним
появится точно эта же подсказка. Поле IP заполняешь адресом из шага 3
(обычно `192.168.137.1`), а не обычным WiFi-адресом ПК.
